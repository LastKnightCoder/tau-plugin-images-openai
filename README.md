# OpenAI 图片

用一句话描述想要的画面，就能得到一张图；手头有参考图，也可以让它照着改。生成的图片可以直接放进聊天、文档和白板，存放位置跟随「资源存储」设置。

## 开始使用

1. 在插件中心安装「OpenAI 图片」，然后在插件页的「已安装」里打开开关，无需重启。
2. 进入本插件详情的「设置」，添加账号，填写服务地址、API Key 和模型名称，点击保存。
3. 到应用「设置 → 图片生成」中把这个账号设为使用中，就可以开始生成了。

服务地址写到 `/v1` 为止，比如 `https://api.openai.com/v1`。用的是别家服务，就填它提供的地址。可以添加多个账号，随时切换。

## 常见问题

**拿参考图修改时报错？** 并非所有模型都支持改图，换一个支持的模型再试。

**提示模型或参数不支持？** 这是服务商返回的错误，换个它支持的模型即可。

**取消后还会扣费吗？** 可能会。取消只是不再等结果，服务商那边已经开始的生成仍可能计费。单次生成最多等待 5 分钟。

## 注意

- 需要 Tau 0.60.2 或更高版本。
- 生成和修改图片会产生服务商费用。
- API Key 请妥善保管，别出现在截图或问题反馈里。
