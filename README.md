# OpenAI 兼容图片

用 OpenAI 或兼容它的服务生成图片，也可以给一张或几张参考图，让它在此基础上修改。生成的图片可以直接用在聊天、文档和白板里，保存方式跟随你的「资源存储」设置。

## 开始使用

1. 在插件中心安装「OpenAI 兼容图片」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开设置里的「图片生成」，添加一个本插件的账号，填写服务地址、API Key 和模型名称。
3. 保存后把它设为当前账号，就可以开始生成图片了。

服务地址填到 `/v1` 为止，例如 `https://api.openai.com/v1`。可以添加多个账号，比如分别对应不同的服务商，彼此互不影响。

## 常见问题

**用参考图修改时报错？** 不是所有服务商都支持用参考图修改图片，请确认你用的服务和模型支持这项功能。

**提示模型或参数不支持？** 这是服务商返回的错误，换一个它支持的模型试试。

**取消了还会扣费吗？** 可能会。取消只是不再等待结果，服务商那边已经开始的生成仍可能计费。一次生成最多等 5 分钟。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 生成和修改图片会产生服务商的费用。
- API Key 不要发给别人，也不要贴在截图或问题描述里。
