# OpenAI 圖片

用一句話描述想要的畫面，就能生成一張圖片；手邊有參考圖，也可以讓它照著修改。生成的圖片可直接放進對話、文件與白板，存放位置跟隨「資源儲存」設定。

## 開始使用

1. 在外掛中心安裝「OpenAI 圖片」，然後在外掛頁的「已安裝」中開啟開關，無需重新啟動。
2. 進入本外掛詳情的「設定」，新增帳號，填寫模型位址、API Key 與模型名稱，點選儲存。
3. 前往應用程式「設定 → 圖片生成」將此帳號設為使用中，即可開始生成。手機端入口位於「我的 → AI → 圖片生成」。

手機對話中可直接要求生成圖片；編輯圖片時附上參考圖，也可以繼續要求修改剛生成的圖片。生成結果會依照「圖片與附件」中的上傳位置儲存。

服務位址填寫至 `/v1` 為止，例如 `https://api.openai.com/v1`。若使用其他服務商，請填寫對方提供的位址。可新增多個帳號並隨時切換。

圖片模型提供 `gpt-image-2`、`gpt-image-2.5-sunburst`、`gpt-image-2.5-flare`、`gpt-image-2.6-sunburst` 與 `gpt-image-2.6-flare` 五個預置項目。也可以展開模型下拉選單，輸入服務商提供的模型名稱，按下 Enter 或點選「使用」確認，再儲存帳號。生成與修改圖片都會使用已儲存的模型名稱，實際可用模型以服務商為準。

## 常見問題

**使用參考圖修改時報錯？** 並非所有模型都支援改圖，請改用支援的模型再試。

**提示模型或參數不支援？** 這是服務商回傳的錯誤，更換為對方支援的模型即可。

**取消後還會扣費嗎？** 可能會。取消只是停止等待結果，服務商端已經開始的生成仍可能計費。單次生成最長等待 5 分鐘。

## 注意事項

- 生成與修改圖片會產生服務商費用。
- 請妥善保管 API Key 金鑰，切勿出現在截圖或問題回饋中。
